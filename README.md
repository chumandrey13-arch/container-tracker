# Контейнеры — дислокация

Веб-приложение для сопоставления рабочего Excel-журнала с отчётами слежения от FESCO и других перевозчиков/экспедиторов. Не предполагает, что все контейнеры принадлежат FESCO.

## Возможности
- Читает все листы журнала, где есть колонка `контейнер` или `номер контейнера`.
- Принимает до пяти Excel-отчётов за раз.
- Сопоставляет по номеру контейнера, показывает клиента и последнюю дислокацию.
- Поиск, фильтры и экспорт CSV.
- Опциональное общее облачное хранение через Supabase: пользователи входят по почте/паролю, загруженные исходные Excel и рассчитанный результат доступны коллегам.

## Важно про общее хранение
Обычный GitHub Pages не хранит данные, загруженные пользователем. Чтобы коллеги видели один и тот же результат, проект подключается к Supabase. Для этого требуется одноразовая настройка.

## Настройка Supabase
1. Создайте проект на https://supabase.com/ и сохраните пароль базы в безопасном месте.
2. В Supabase откройте **SQL Editor → New query**, скопируйте весь `supabase-setup.sql` и нажмите **Run**.
3. Откройте **Project Settings → API** (или раздел API Keys) и скопируйте Project URL и публичный `anon`/`publishable` key.
4. Откройте `config.js`, замените `https://YOUR_PROJECT.supabase.co` на Project URL и `YOUR_SUPABASE_ANON_KEY` на публичный ключ.
   - В `config.js` нельзя вставлять `service_role` или secret key.
5. В Supabase откройте **Authentication → Sign In / Providers** и отключите публичную регистрацию (Allow new users to sign up), если она включена.
6. В **Authentication → Users** добавьте пользователей коллег вручную: Add user, рабочая почта, временный пароль. Передайте пароль безопасным способом; коллега может затем сменить его согласно возможностям проекта.
7. Загрузите в GitHub файлы `index.html`, `config.js`, `README.md`, `supabase-setup.sql`, `.nojekyll`.
8. Включите GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Как пользоваться после настройки
1. Откройте опубликованный сайт и войдите по рабочей почте и паролю.
2. Выберите журнал и до пяти отчётов слежения.
3. Нажмите **Сопоставить файлы**. Если вход выполнен, приложение сохранит оригиналы Excel в приватном Supabase Storage и результат в общей базе.
4. Коллега открывает ту же ссылку, входит своей учётной записью и нажимает **Загрузить общий результат**.
5. Чтобы обновить данные, загрузите свежий журнал и свежие отчёты и снова нажмите «Сопоставить файлы».

## Безопасность и ограничения
- Доступ к базе и файлам доступен только вошедшим пользователям Supabase. Не включайте публичную регистрацию для внутреннего рабочего инструмента.
- Данные результатов сохраняются как снимки; экран «Загрузить общий результат» показывает самый последний снимок.
- В текущей версии оригинальные файлы сохраняются в приватном bucket, но интерфейс для скачивания исходных файлов пока не предусмотрен.
- Файлы не отправляются на GitHub, но загружаются в ваш проект Supabase при общем сохранении. Учитывайте корпоративные требования к хранению данных и выберите подходящий регион проекта.
- Для чтения Excel используется SheetJS CDN, поэтому браузеру нужен интернет.
- Это не прямое подключение к API FESCO: новые отчёты загружаются вручную.
